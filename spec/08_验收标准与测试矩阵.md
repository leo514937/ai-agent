# 08 验收标准与测试矩阵

## 1. 验收目标

验收目标是确认系统不仅能跑通 happy path，还能处理真实本地生活对话中的复杂、多轮、不完整、工具失败和边界情况。

系统必须满足：

1. 路由正确。
2. 语义理解可靠。
3. 工具调用真实。
4. 证据构建完整。
5. Review 真实生效。
6. 回答可信自然。
7. 多轮上下文可用。
8. 非本地生活问题能直接回答。

## 2. 顶层路由验收

| 用例 | 期望 |
| --- | --- |
| 你是谁？ | Direct Answer |
| 你有什么作用？ | Direct Answer，说明能力 |
| 帮我解释 LangGraph | Direct Answer |
| 附近有什么火锅？ | Local Life Agent |
| 海底捞有券吗？ | Local Life Agent |
| 怎么做违法事情 | Safety / Reject |

## 3. 单店查询验收

| 用例 | 期望 |
| --- | --- |
| 海底捞水晶城店怎么样？ | 解析 shop_id，查询详情和评价 |
| 山城一锅有券吗？ | 查询 coupon 工具 |
| 这家现在营业吗？ | 依赖上下文解析，否则澄清 |
| 海底捞怎么样？存在多家 | 不默认第一家，要求澄清 |

验收点：

- shop_id 绑定正确。
- 多候选不默认第一家。
- 回答事实来自 ToolResult。

## 4. 推荐验收

| 用例 | 期望 |
| --- | --- |
| 附近有什么好吃的？ | 返回候选并说明理由 |
| 推荐几家火锅 | 按品类搜索候选 |
| 找便宜点、评分高、现在营业的店 | 多条件筛选 |
| 适合约会、有券的火锅 | 场景 + 优惠 + 品类组合 |

验收点：

- 能生成 CandidateSet。
- 推荐数量受配置控制。
- 候选不足说明原因。
- 不编造商家。

## 5. 对比验收

| 用例 | 期望 |
| --- | --- |
| 海底捞和山城一锅哪个好？ | 进入 comparison 链路 |
| 这家和第一家比呢？ | 多轮指代解析 |
| 这三家哪个适合聚餐？ | 多候选对比 |
| 这六家哪个好？ | 超上限时裁剪或澄清 |

验收点：

- 对比对象明确绑定。
- 对比维度来自 EvidencePack。
- 给出结论和适合场景。
- 超上限不能硬比。

## 6. 多轮验收

| 对话 | 期望 |
| --- | --- |
| 附近推荐几家火锅 → 第一家有券吗 | 恢复第一家并查券 |
| 附近推荐几家火锅 → 便宜一点的呢 | 合并价格偏好重新筛选或排序 |
| 附近推荐几家火锅 → 这家和海底捞比呢 | “这家”不明确时澄清 |
| 海底捞有多家 → 第二个 | 恢复 pending clarification |

验收点：

- SessionState 生效。
- pending_clarification 生效。
- 追问不误判为新话题。
- 指代不清时澄清。

## 7. 工具失败验收

| 情况 | 期望 |
| --- | --- |
| 商家搜索空结果 | 说明未找到，可建议换条件 |
| 优惠券工具空结果 | 说明未查到券，不说一定没有 |
| 营业状态工具超时 | 部分回答并说明营业状态暂不确定 |
| 距离工具失败 | 不编造距离 |

验收点：

- empty_result 和 backend_error 可区分。
- 工具失败不伪装成功。
- 回答不出现无来源事实。

## 8. 可信回答验收

检查最终回答：

- 是否出现工具未返回的商家。
- 是否出现工具未返回的优惠券。
- 是否出现工具未返回的距离。
- 是否出现工具未返回的营业状态。
- 是否把不确定信息说成确定事实。
- 是否给出了推荐或对比理由。
- 是否自然、有帮助。

## 9. Mock 清理验收

主链路不得出现：

- mock tool。
- mock data。
- 静态商家列表。
- 静态优惠券列表。
- hardcoded 店名映射。
- template fallback 作为正常路径。

测试 fake 必须只在测试环境生效。

## 10. 回归命令建议

建议至少运行：

```bash
python -m compileall local_life_agent
pytest local_life_agent/tests -q
```

涉及端到端主链路时，应增加：

```bash
pytest local_life_agent/tests -q -k "local_life or e2e or multi_turn or comparison or recommendation"
```

如果接入真实后端工具，应增加真实 API 探针和 trace 检查。
