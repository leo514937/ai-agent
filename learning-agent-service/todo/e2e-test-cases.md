# 端到端测试用例文档

> 测试入口：`POST /internal/v1/chat/stream`
> 测试方式：前端输入，观察 SSE 返回的最终回答

---

## 执行说明

1. **环境准备**：确保 Python 服务和 Java 服务均启动
2. **测试工具**：使用前端页面或 curl/Postman 发送请求
3. **请求格式**：
   ```json
   {
     "user_id": "test_user",
     "session_id": "test_session_001",
     "trace_id": "trace_test_001",
     "message": "输入内容",
     "client_context": {}
   }
   ```
4. **验证方式**：观察 SSE 流中的 `final` 事件，检查 `answer_text` 内容
5. **日志查看**：检查 `var/local-logs/python-service.log` 中的路由决策
