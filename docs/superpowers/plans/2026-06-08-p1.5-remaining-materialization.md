# P1.5 Remaining Materialization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 补齐 P1.5 尚未落地的图结构与分层能力：标准路径的 `rule_review / merge_rank_node / contract_review`、复杂路径的 planner 闭环拆分、以及 RAG 的 recall/filter/rerank/evidence 分层。

**Architecture:** 尽量复用现有 `application/router` 契约与 `application/workflow` 编排，只在当前模块里新增清晰节点和薄包装，避免引入新大包。标准路径以 `SourceContract` 和 `AnswerContract` 为核心约束，complex path 保持 `plan_execute` 独立闭环，RAG 则把现有单体 pipeline 拆成可单测的分层函数，再由图节点串起来。

**Tech Stack:** Python 3.11, existing LangGraph workflow, Pydantic models, pytest, existing local_life contract/answer/rag helpers.
