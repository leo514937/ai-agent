# 7. 测试计划

> 按 P0/P1/P2 分级，覆盖单元测试、集成测试、回归测试、全链路端到端测试。
> 目标是确保改造不破坏现有场景，同时完整覆盖所有新增场景。

---

## 7.1 测试策略

### 分层

| 层级 | 范围 | 工具 | 目标 |
|------|------|------|------|
| 单元测试 | 单个函数/类 | pytest, mock ToolCallGateway | 覆盖 CandidateSpec resolve 的逻辑分支 |
| 组件测试 | 单个 node handler | pytest, mock state | 覆盖 _h_target_resolve 拆出的子函数 |
| 集成测试 | 子图 | pytest, partial mock | 覆盖 discovery→evidence 链路 |
| 回归测试 | 现有全链路 | 现有 gateway 22 测试 | 确保 0 回归 |
| 端到端 | 真实 LLM + gateway | pytest + fake_llm | 覆盖 7 个标杆测试用例 |

### 测试数据

| 数据源 | 内容 | 用途 |
|--------|------|------|
| `tests/fixtures/shop_search_results.json` | search_shops 返回结果 | discovery comparison mock |
| `tests/fixtures/resolve_shop_results.json` | resolve_shop 返回结果 | explicit comparison mock |
| `tests/fixtures/session_states.json` | 各种 session state 样本 | context comparison mock |
| `tests/fixtures/semantic_frames.json` | 各种 LLM 解析结果 | intent_parser/slot_extractor 测试 |

### 端到端测试实施方法

```python
# tests/test_e2e_candidate_set.py
import pytest
from local_life_agent.engine.graph_builder import build_graph

@pytest.mark.parametrize("test_input,expected_pattern", [
    # 测试用例 1: discovery comparison
    ("对比附近评分最高的两家KTV", "两家"),
    # 测试用例 2: mixed signals
    ("附近评分最高和距离最近的火锅店比一下", "对比"),
    # 测试用例 3: mixed ordinal + explicit
    ("刚才推荐的第三家和海底捞哪个好", "海底捞"),
    # 测试用例 4: mixed deictic + discovery
    ("这家店和它附近评分最高的店比一下", "评分最高"),
    # 测试用例 5: explicit comparison (regression)
    ("对比海底捞和山城一锅", "对比"),
    # 测试用例 6: recommendation (regression)
    ("推荐一家火锅店", "推荐"),
    # 测试用例 7: context refine
    ("刚才推荐的第一家优惠券多吗", "优惠券"),
])
def test_e2e_candidate_set_flow(test_input, expected_pattern):
    graph = build_graph()
    result = graph.invoke({"user_input": test_input})
    assert result["final_response"] is not None
    assert expected_pattern in result["final_response"]
```

## 7.6 回归测试执行流程

### 每次代码修改后的验证步骤

```
1. 修改代码
2. 运行 lsp_diagnostics → 0 错误
3. 运行受影响模块的单元测试
   pytest tests/test_candidate_spec.py -v
   pytest tests/test_candidate_resolver.py -v
   pytest tests/test_target_resolve.py -v
4. 运行回归测试
   pytest tests/test_discovery_comparison.py -v  # 新增
   （持续集成中增加发现类测试）
5. 运行现有 gateway 测试
   pytest tests/ -k "gateway" -v
   → 必须全部通过
6. 运行全量测试
   pytest tests/ -v
   → 0 failed
7. 手动验证 7 个标杆用例
```
