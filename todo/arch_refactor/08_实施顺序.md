## 8.9 回退计划

### 如果在实施中发现重大兼容问题

1. **保留旧路由**：不删除 `task_router`，新增 `GoalPlanner` 只在 `candidate_source` 非空时激活
2. **feature flag**：`use_candidate_set_v2 = False` 默认关闭，显式开启
3. **暂缓 P2**：如果 P1 完成时已经覆盖所有 target 场景，P2 可推迟至下一迭代
4. **紧急回退**：`git revert + git stash` 秒回

### 风险触发条件

| 条件 | 行动 |
|------|------|
| `_h_target_resolve` 重构后有 case 回归 | 回退到旧函数，使用新函数仅处理 discovery 分支 |
| semantic_parse 的新字段导致 LLM 输出不稳定 | 关闭 LLM 解析候选条件，仅使用 slot_extractor 规则推断 |
| discovery 搜索质量不可接受 | 在回答模板中降低发现候选的置信度，增加"根据已有数据"前缀 |
